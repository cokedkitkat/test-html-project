# WILD — Wildlife Field Guide

WILD is a responsive, browser-based wildlife education project built with HTML, CSS, and vanilla JavaScript. This version keeps the original natural, editorial visual identity and expands it into a learning experience.

## Features

- Responsive layout for desktop, tablet, and mobile
- Search by common name, scientific name, habitat, range, diet, group, or status
- Animal-group filters and sorting
- Saved species using browser local storage
- Light/dark theme preference
- Species detail modal with habitat, range, diet, conservation status, and a did-you-know fact
- Short multiple-choice wildlife quiz with feedback and score
- Accessible labels, keyboard support for species cards, and reduced-motion support
- No build tools or package installation required

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. An internet connection is needed for remote photography and web fonts. The main features run in the browser without a backend.

## Project files

- `index.html` — current WILD experience
- `encyclopedia.html` — original version retained for comparison

## Important note on educational data

Species summaries are introductory learning content, not a substitute for current scientific or conservation advice. Conservation categories and populations can change and may differ by species or regional population. Verify details using the IUCN Red List and other reputable conservation or scientific sources. Links in the site open external references; this prototype does not have an API backend.

## Image credits

Images are loaded from remote image URLs. Before submitting or publishing the project, review the license and attribution requirements for each image and keep a clear record of its source. Wikimedia Commons and Unsplash have their own licensing terms.
